NEAR DUPLICATES
A deterministic SimHash screen was run over 3,529 snippets of at least 100 characters (4-token shingles; Hamming distance <=3). It flagged 705 candidate pairs: 69 cross-CVE pairs and 37 cross-category pairs. These are only review leads, not confirmed near-duplicates; no human adjudication was performed and short snippets were excluded. Common boilerplate can create false positives, while function changes can create false negatives. Existing detect_near_duplicates.py loads code from exclusion_manifest.json (historical evaluation metadata), not the current category snippets. Follow up with function-level comparison and manual review after repository/CVE lineage is joined.
